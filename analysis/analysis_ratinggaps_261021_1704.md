## Interface

Removed the decorative masthead labels, tagline and redundant matching-list heading. All four control icons are 16×16 SVGs. Pareto tradeoffs shows three successive nondominated sets: red, blue, dark yellow. Every book in a layer, including coordinate ties, is removed before the next layer is computed. Only matching books with both coordinates qualify; curves are visual guides, not dominance tests. The HTML budget is 1,500 bytes times the number of recommended plus vetoed books.
